## Enunciat de la practica:
Fes una calculadora interactiva amb Python.
Primer ha de demanar les dades necessàries (no cal que sigui en aquest ordre, tu mateix).
Els valors poden ser números enters o amb decimals.

* Demanar el primer número.
* Demanar el segon número.
* Preguntar quina operació es vol fer (ha de ser un dels següents símbols: + - * / %).

Finalment, ha de mostrar el resultat de l'operació.

S'ha de fer que el programa es repeteixi contínuament fins que no reconegui la operació (per exemple si l'usuari escriu $ quan se li demana quina operació vol fer).

**Recorda de fer servir noms variables amb camelCase i també comentar el codi.**
